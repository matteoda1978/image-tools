How to Compress an Image

  1. Choose one or more JPG, PNG or WebP images.
  2. Select the output format and image quality.
  3. Optionally set a maximum width or target file size.
  4. Click Compress images and download the results.

Frequently Asked Questions

How can I compress an image online for free?

Select your image, choose the quality and output format, then click the compress button. You can download the compressed result directly from your browser.

Does this image compressor upload my files?

No. Image processing is performed locally in your browser. The tool does not send selected image files to our server.

Which image formats are supported?

You can select JPG, JPEG, PNG and WebP images. The output can be JPG, PNG or WebP.

Will compressing an image reduce its quality?

It depends on the output format and settings. JPG and WebP quality settings can reduce file size with some loss of image detail. PNG output is lossless, although converting another format to PNG may not make the file smaller.

Can I compress an image to an exact file size?

The target size setting makes an attempt to reduce JPG or WebP output toward the requested size. An exact size cannot be guaranteed for every image. PNG does not use the target-size adjustment.
