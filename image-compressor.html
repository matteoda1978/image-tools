How to Compress Multiple Images

  1. Select JPG, PNG or WebP images from your device.
  2. Optionally enter a maximum width or height.
  3. Keep image proportions enabled to avoid stretching photos.
  4. Choose an output format and quality setting.
  5. Optionally set a target file size for JPG or WebP images.
  6. Click Compress Images and wait for processing to finish.
  7. Compare the file sizes and download your results individually or as a ZIP.

Choose the Best Image Format

WebP

WebP can provide a useful balance between file size and visual quality. It is often a good choice for website images.

JPG

JPG is widely supported and is commonly used for photographs. Lower quality settings can reduce file size, although some image detail may be lost. JPG does not support transparency.

PNG

PNG uses lossless compression and supports transparency. It is useful for graphics and screenshots, but PNG output is not necessarily smaller than the original file.

Frequently Asked Questions

Can I compress 50 images at once?

Yes. Select up to 50 supported images and apply the same settings to the whole batch.

Can I resize images and compress them at the same time?

Yes. Enter the maximum width and/or height before processing. Images can be resized and compressed in the same operation.

Will the compressed image always be smaller?

No. The result depends on the original image, output format, dimensions and quality. Some images may become larger, especially when converting to PNG.

Can I specify a target file size?

You can set a target size for JPG and WebP. The tool attempts to reduce quality to approach that target, but it cannot guarantee an exact file size.

Are my images uploaded to a server?

The image processing takes place locally in your browser. This tool does not upload your selected image files to our server. The optional ZIP library is loaded from an external CDN.
