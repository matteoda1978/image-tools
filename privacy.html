3. Images and files processed by the tools

The way files are handled depends on the individual tool. Not every feature uses the same processing method.

Tools that process files in your browser

Several tools are designed to process selected images directly in your browser. For these operations, the image itself is not intentionally uploaded to a RitoccaPix image-processing server.

Examples include image conversion and editing tools, Photo to Coloring Page, Image Smart, Object Remover, Pixel Avatar Maker and AI Study Assistant, according to their current implementations.

Some of these pages load JavaScript libraries, OCR software, AI runtimes or model files from external content delivery networks or model hosts. Those providers may receive technical information when your browser requests those resources.

Photo to Coloring Page

This feature has a separate account and AI processing workflow. Users may create an account, verify an email address, sign in and use available processing credits.

The account and authentication functions use Supabase. Account-related information may include an email address, authentication and session information, and credit balance data.

When a user requests an AI-generated coloring page, the selected image and processing settings are sent to a RitoccaPix Cloudflare Worker. The request uses an authenticated session. The image is therefore not processed exclusively in the browser.

Do not upload confidential or sensitive images unless you have considered this external processing and the relevant provider policies.

AI Study Assistant

The current version extracts text from uploaded PDFs and images in the browser. It uses external PDF and OCR libraries loaded from public CDNs when needed.

The current version creates study materials using local text-processing rules and is not connected to a generative AI tutor service.

4. Accounts and credits

The Photo to Coloring Page feature allows users to register and sign in. The account service is provided through Supabase.

Information processed for this feature may include the email address supplied during registration, authentication data, session tokens and information about available credits.

Account information is used to provide authentication, manage access to the feature and check available credits. The service may also send account-related emails, such as email verification messages.

For more information about the provider, consult Supabase's Privacy Policy .
