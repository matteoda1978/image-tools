Upload your photo

Choose a JPG, PNG or WebP image from your device. The preview will show the image dimensions once it loads.

Paint over the object

Adjust the brush size and drag over the unwanted area. Use Undo or Clear selection if you need to correct your marks.

Review your selection

Zoom in to inspect the marked area. You can download the original image, but automatic object removal is not available yet.

Important: selection is not removal

This page currently lets you mark an area of an image and download the original photo. It does not yet use AI to erase objects or reconstruct the background. A working object-removal service needs an additional image-processing or AI backend.

Frequently asked questions

Useful information before you start editing.

Can I remove objects from an image for free?

This page is free to use for marking areas in a photo. Automatic object removal is not currently available because the required AI processing service has not been connected.

How do I select an unwanted object?

Upload your image, choose a brush size and drag across the object. The highlighted overlay shows the area you have marked.

Which image formats are supported?

The editor accepts JPG, PNG and WebP images up to 20 MB. You can download the original image as a PNG file.

Does the download contain the object-free image?

No. The download contains the original photo, without the selection overlay. The marked object is not erased.

Can I use the editor on a phone?

Yes. The page layout adapts to smaller screens. For more precise selections, a larger screen may be easier to use.
