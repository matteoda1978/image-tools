Anteprima

Analizza un'immagine online

L'analizzatore di Image Tools permette di controllare rapidamente le principali caratteristiche di un'immagine senza installare programmi.

Quali informazioni vengono visualizzate?

  • Nome del file
  • Formato dell'immagine
  • Larghezza e altezza in pixel
  • Dimensione del file
  • Rapporto d'aspetto
  • Numero totale di pixel
  • Orientamento dell'immagine
  • Presenza di trasparenza

Perché controllare le dimensioni?

Conoscere dimensioni e peso di un'immagine è utile prima di pubblicarla su un sito web, sui social network o di inviarla tramite email.

Le immagini vengono caricate online?

No. L'analisi viene effettuata direttamente nel browser sul dispositivo utilizzato.

Domande frequenti

È gratuito?

Sì, l'analizzatore può essere utilizzato gratuitamente.

Funziona da smartphone?

Sì. Puoi selezionare un'immagine direttamente dalla galleria del tuo smartphone o tablet.

Posso analizzare fotografie molto grandi?

Il funzionamento dipende dalle capacità del browser e del dispositivo. L'elaborazione viene eseguita localmente.
