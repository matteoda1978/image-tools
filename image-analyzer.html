How does the image analyzer work?

This free tool lets you quickly check an image’s technical properties without installing software. Choose a file and the results will appear automatically.

What information can you check?

  • Format: the image type, when identifiable by your browser.
  • Dimensions: width and height in pixels.
  • File size: the file size in KB or MB.
  • Aspect Ratio: the ratio between width and height.
  • Pixel Count: the total number of pixels in the image.
  • Orientation: landscape, portrait or square.
  • Transparency: an indication of whether the image contains transparent pixels.

Are images uploaded to a server?

Analysis runs in your device’s browser. This tool’s code does not intentionally send the image to a server. Privacy may still depend on other features or scripts running on the website.

Frequently Asked Questions

Is this tool free?

Yes. You can use the analyzer for free without creating an account.

Which images can I analyze?

You can try image formats supported by your browser, such as JPEG, PNG, GIF, WebP and other compatible formats.

What does aspect ratio mean?

It describes the relationship between an image’s width and height. For example, a 1200 × 800 pixel image has a 3:2 aspect ratio.

Can I use this tool on my phone?

Yes. The page is designed to work on smaller screens too.
