What makes this different?

A neural network, not just interpolation. A conventional resize stretches existing pixels. This tool uses an ESRGAN model trained for image super-resolution to estimate a sharper-looking 2× result.

Frequently asked questions

Is this a real AI image enhancer?

Yes. It uses an ESRGAN neural-network model through UpscalerJS and TensorFlow.js. It creates a 2× super-resolution output; it is not simply changing the image dimensions with a canvas resize.

Are my photos uploaded?

No. Image pixels are processed in your browser. The browser does download the JavaScript runtime and model files from a CDN, but your selected photo is not sent to RitoccaPix's server.

Why is the first run slower?

The browser must download the runtime and AI model the first time. The model may be cached by your browser for later use. Processing time also depends on your device. This version uses a smaller working copy to reduce processing time and memory use.

Can AI restore the exact original details?

No. Super-resolution estimates details and may introduce artifacts. Keep the original file and compare the output before using it for important work.

Can I upload a large photo?

Yes. Large files can be selected, but the tool automatically creates a smaller working copy of up to 1024 px per side and about 1 megapixel before AI processing. The 2× result is based on that working copy, so it may be smaller than 2× the original full-size photo. This helps avoid browser memory errors.
