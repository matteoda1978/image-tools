Come funziona Smart Image Fix?

Smart Image Fix ridimensiona e comprime l'immagine in base all'utilizzo scelto. Puoi verificare le dimensioni, il peso e l'anteprima prima di scaricare il risultato.

  • Sito web: equilibrio tra qualità e peso.
  • Social media: immagini adatte alla condivisione.
  • Email: maggiore attenzione alla riduzione del peso.
  • Uso generale: impostazioni orientate alla qualità.

Come viene ridimensionata la foto?

Se l'immagine supera la larghezza prevista, viene ridimensionata mantenendo le proporzioni. Non viene ritagliata e non viene deformata intenzionalmente.

Il file finale è sempre più leggero?

No. Il risultato dipende dalla foto di partenza e dalla compressione. Se il file finale è più grande, lo strumento lo segnala invece di dichiarare un risparmio inesistente.

Le immagini sono private?

L'elaborazione avviene localmente nel browser. Il codice di questa pagina non invia l'immagine a un server per ottimizzarla.
