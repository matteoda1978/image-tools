Come funziona Smart Image Fix?

Lo strumento analizza automaticamente l'immagine e applica impostazioni differenti in base all'utilizzo scelto.

  • Sito web: punta a un buon equilibrio tra qualità e peso.
  • Social media: mantiene dimensioni adatte alla condivisione.
  • Email: privilegia file più leggeri.
  • Uso generale: mantiene una qualità più elevata.

Perché utilizzare l'ottimizzazione automatica?

Non è necessario conoscere il livello di compressione ideale. Smart Image Fix parte dalle caratteristiche del file e applica automaticamente una configurazione coerente con l'utilizzo scelto.

Le immagini vengono caricate su un server?

No. L'elaborazione viene eseguita direttamente nel browser del dispositivo.
