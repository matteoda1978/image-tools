Frequently Asked Questions

How do I compress an image to 100KB online?

Select one or more images, enter 100KB (or another limit), and click Compress Images. Check the final size shown for each file, then download the results individually.

Will every image become smaller than 100KB?

The tool adjusts image quality and, if needed, image dimensions. Check the status and final size shown for each result. If a target is too small to reach while preserving useful detail, choose a larger limit or accept a smaller image dimension.

Are my images uploaded to a server?

No. Compression takes place locally in your browser. The selected image files are not sent to a RitoccaPix image-processing server.

Can I compress PNG images?

Yes. You can open PNG files and export them as JPG or WebP. These formats do not preserve PNG transparency in the same way, so check the result before using it.

Is this image compressor free?

Yes. You can use this tool for free in your browser without installing an application.
